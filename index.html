Platform support

One studio. Three workflows.

TikTok

Local export works without API access. Optional Login Kit and Content Posting API integration sends a local video to your TikTok inbox. It requires platform approval and your consent. Copy the caption separately.

Facebook

The developer connector supports Reels for Facebook Pages using a Page access token and a local file or hosted video URL.

Instagram

The developer connector supports Reels for professional accounts. The current version requires a publicly accessible HTTPS video URL.

API integrations are an early developer implementation; live authorization and publishing validation are still pending. There is no automatic scheduling or TikTok Direct Post. SocialForge is not affiliated with or endorsed by TikTok or Meta.

Independent & local

Your workspace lives on your Mac.

Drafts stay in the desktop app. Saved platform credentials use macOS secure storage. Content is sent to a platform when you initiate an upload or publish action.
